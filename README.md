📋 ToDoProject
ToDoProject is a web application for managing a task list, built using React, TypeScript, and SCSS. This project was developed as part of the learning process at Mate Academy.

🔗 Live Demo
Check out the live application here:
👉 https://davidkuznets.github.io/ToDoProject/

🛠️ Technologies Used
⚛️ React 18

🟦 TypeScript

🌐 GitHub Pages for deployment

⚙️ Features
➕ Create, ✏️ edit, and ❌ delete tasks

🔍 Filter tasks by status: All, Active, Completed

✅ Mark all as completed & 🧹 clear completed tasks

💾 Persist tasks in browser local storage

📱 Fully responsive design for mobile devices
